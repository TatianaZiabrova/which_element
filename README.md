# Какой ты химический элемент сегодня?

Шуточный тест Татьяны Зябровой, репетитора по химии и биологии. Канал: [@schoolusu](https://t.me/schoolusu).

Восемь вопросов про настроение, десять элементов, сохранение результата в PNG и отправка друзьям. Работает прямо в браузере: без регистрации, базы данных, платных сервисов и постоянно включённого компьютера.

## Как включить сайт — один раз

1. Войди в GitHub под аккаунтом **TatianaZiabrova**.
2. Открой [настройки Pages этого репозитория](https://github.com/TatianaZiabrova/which_element/settings/pages).
3. В разделе **Build and deployment** найди **Source** и выбери **Deploy from a branch**.
4. Ниже, в **Branch**, выбери **main**, рядом оставь **/ (root)**.
5. Нажми **Save**.
6. Подожди несколько минут. GitHub предупреждает, что первая публикация может занять до 10 минут.
7. Открой **https://tatianaziabrova.github.io/which_element/**. Эту ссылку можно отправлять подписчикам.

Всё! После включения Pages ноутбук можно выключать. Сайт будет работать на GitHub. При следующих изменениях файлов в ветке `main` он обновится автоматически.

Если появляется 404: проверь, что выбраны `main` и `/ (root)`, затем посмотри [вкладку Actions](https://github.com/TatianaZiabrova/which_element/actions): публикация должна завершиться зелёной отметкой. Если настройка Pages недоступна на бесплатном аккаунте, проверь публичность репозитория: GitHub Free поддерживает Pages из публичных репозиториев. Смену видимости приватного репозитория нужно отдельно обдумать, она открывает все его файлы.

После публикации полезно один раз открыть ссылку с телефона через мобильный интернет: доступность зарубежных сервисов зависит от сети.

Основа инструкции: [официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [срок первой публикации](https://docs.github.com/en/pages/quickstart). Проверено 17 сентября 2026 года.

## Как сохранить результат

Пройди тест и нажми «Сохранить карточку». Скачается PNG 1080 × 1350. Если телефон вместо скачивания открывает картинку, удерживай её и выбери сохранение изображения. Кнопка «Поделиться с друзьями» открывает системное меню там, где оно доступно; иначе копирует текст и ссылку. Ответы в ссылку не попадают.

## Где что менять

- `data.js` — вопросы, варианты, баллы, описания элементов и советы.
- `styles.css` — цвета, размеры, мобильная вёрстка.
- `app.js` — прохождение, подсчёт, сохранение и отправка карточек.
- `index.html` — имя автора, ссылка на канал, название и описание сайта.
- `CONCEPT.md` — описание принятой концепции.
- `.nojekyll` — пустой файл для публикации статических файлов без обработки Jekyll. Не удалять.

В каждом ответе первый элемент получает 2 балла, второй — 1. При равенстве побеждает элемент с большим числом основных ответов; затем используются последние ответы. Одинаковые ответы всегда дают один и тот же результат. Смена даты сама по себе результат не меняет.

## Локальная проверка для разработчика

Установка зависимостей и сборка не нужны. В папке сайта выполни `python3 -m http.server 3124`, затем открой `http://localhost:3124/`. Двойной щелчок по HTML не подходит: браузер ограничивает модули JavaScript при открытии файлов напрямую.

Проверка подсчёта: `npm test` (Node.js 20+). Перебирает все 390 625 комбинаций и проверяет достижимость всех элементов. Проверка PNG: `http://localhost:3124/tests/cards.html` — все 10 карточек, реальные размеры и контроль переполнения текста.

Сайт не отправляет ответы на сервер, не использует cookies, внешние шрифты или собственную аналитику. Хостинг может вести стандартные технические журналы запросов.
