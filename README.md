# Какой ты химический элемент сегодня?

Привет! Я Татьяна Зяброва, репетитор по химии и биологии. Это мой шуточный репозиторий — небольшой тест, в котором химические свойства превращаются в описания настроения.

Восемь вопросов помогут узнать, какой ты элемент сегодня: готовый к приключениям натрий, невозмутимый неон или кто-то ещё. Результат можно сохранить на карточке и отправить друзьям.

Я придумала этот тест просто для улыбки и интереса к химии. Это не психологическая диагностика — завтра настроение и элемент могут быть другими!

## Статистика

Сайт считает посещения через [GoatCounter](https://www.goatcounter.com): без кук, без сторонних библиотек, без сбора ответов — уходят только метки.

Настройка: код сайта задаётся строкой `const SITE` в начале [`analytics.js`](analytics.js). Статистика — на [schoolusu.goatcounter.com](https://schoolusu.goatcounter.com).

Что попадает в панель:

| Метка | Что означает |
| --- | --- |
| просмотр страницы | зашёл на сайт |
| `step-01` … `step-08` | дошёл до этого вопроса |
| `finish` | дошёл до результата |
| `element-Na` и другие | какой элемент выпал |

Зашедшие, но не начавшие тест — это посетители минус `step-01`. Бросившие на середине видны по тому, на каком `step` обрывается цепочка. Каждая метка уходит не больше одного раза за визит, так что кнопка «Назад» и повторное прохождение цифры не накручивают.
